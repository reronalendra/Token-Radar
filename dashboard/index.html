TOKEN RADAR

Which pre-token protocol would be worth the most if it launched a token today?

Every protocol below has no token yet. Each one is scored from the snapshot's own figures — its TVL, its seven-day growth, how long it has run with no token, and how many chains it reaches — and ranked by the implied value that scoring gives. The implied value is this radar's own claim, not a prediction that a token will launch, or when.

How the model works

implied value = TVL × 0.30 × growth × maturity × breadth

  • Growth — 1 + clamp(7-day change, −50%, +150%) ÷ 100 × 0.60. One wild week cannot crown a protocol.
  • Maturity — 0.55 + min(age, 4 years) ÷ 4 years × 0.45. Older protocols that still have no token have had longer to earn a launch.
  • Breadth — 1 + 0.03 per extra chain, up to 5. A protocol on several chains reaches more wallets.
  • Separation — protocols whose token already trades are never ranked here. They sit apart, at their market's own value, on the Live tokens tab.

Method: the board ranks every pre-token protocol that passes the watchlist's own rule — no token, not a centralised exchange, not a versioned pool, not a wrapped, staked or bridged product. The watchlist (40 protocols at or above $50M TVL) is the floor, never the ceiling: 163 more protocols below and above it are ranked on the same terms.

Implied value is an estimate from public TVL figures, not financial advice and not a prediction of a launch. Farm plans describe on-chain actions with their cost and time; check the protocol's own site before you act, and never pay to claim an airdrop.
