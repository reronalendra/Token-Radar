A token launch radar dashboard: 203 protocols ranked by implied value from TVL, 7-day growth, maturity and chain breadth, with concrete farm plans for each. Dark dashboard with board, detail view, search, filters and sorting.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
